# Figure 1e: Cell-type abundance across tissues

**`M01e_organ_celltype_relative_abundance_plot_data.tsv`**

Cell counts and within-organ fractions for each cell type. The `percentage` column is 100 times `fraction`; weighted abundance is calculated separately by the analysis scripts.

See `../01_Code/README.md` for the scripts that use or generate these tables. `data_dependencies.tsv` records shared-resource paths; additional inputs are listed in the project-level [input-file list](../../../00_Settings/00_External_Data_Dependencies.tsv).

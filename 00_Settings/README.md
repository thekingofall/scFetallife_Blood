# Data and analysis setup

The study data record is [Zenodo: 10.5281/zenodo.22952935](https://doi.org/10.5281/zenodo.22952935). The cell atlas `00_Global_Data/Fetal_Immune_Atlas.h5ad` is included through Git LFS. Download the TCR/BCR h5ad objects, flow-cytometry proportions and Olink NPX workbook from Zenodo into `00_Global_Data`, keeping their filenames. The sample metadata, single-cell pseudobulk TPM and PHA bulk TPM tables are included in this repository under `00_Global_Data`.

For flow-cytometry preprocessing, download all five FCS ZIP files from the Zenodo record and extract each into `00_Global_Data/Flow_Data`. The archives contain the `fetal flow data/fcs blood` and `fetal flow data/fcs organ` directories. Place the three additional files in `00_Global_Data/Flow_Data/fetal flow data` with these names:

| Zenodo filename | Local filename |
| --- | --- |
| `Fetal_Immune_Atlas_Flow_Blood_23Color.wsp` | `23color 20240526 blood.wsp` |
| `Fetal_Immune_Atlas_Flow_Organs_24Color.wsp` | `24color 20240526 organ.wsp` |
| `Fetal_Immune_Atlas_Flow_Sample_Metadata.xlsx` | `fetal sample information of spectral flow data.xlsx` |

The cell atlas h5ad and the six larger CellChat and NK trajectory objects in `00_Global_Data/Shared_Inputs` use Git LFS. Install [Git LFS](https://git-lfs.com), then run the following commands in the cloned repository:

```sh
git lfs install
git lfs pull
```

Shared plotting tables are under `00_Global_Data/Shared_Inputs`. Panel READMEs link to their inputs. The Seurat expression object for CellChat fitting is generated by the [Figure 3 preprocessing scripts](../Main_Figure_03/00_Preprocess/README.md).

`00_External_Data_Dependencies.tsv` lists data paths relative to the repository root. `00_Panel_Code_Index.tsv` lists the R and Python scripts by panel. Main figures 1–8 and supplementary figures 1–18 are arranged into 100 panel directories. Their `01_Code/README.md` files describe the calculations, inputs and output files.

## R environment

`R_package_versions.tsv` and `Preprocess_Python_Versions.tsv` list the software versions specified for the analyses. Packages named in Methods use the manuscript versions; other packages have reference dependency versions.

`00_setup_R.R` configures the optional project R library and checks installed package versions against `R_package_versions.tsv`. When the configured library directory is unavailable, R uses its current library paths. Set the `SCF_R_LIB` environment variable to select another library. Missing packages are listed in an error message; version differences are reported without stopping execution.

```sh
Rscript 00_Settings/00_setup_R.R
```

## Running analyses

Run the numbered scripts in the order described in the panel README. The scripts resolve data paths from their own location. Figure outputs are written to `02_Figures` as PDF and PNG. Receptor chain classification and clonotype networks use Scirpy 0.12.0, Scanpy 1.9.3, AnnData 0.10.7 and NumPy 1.23.4.

The shared CellChat workflow is in `Main_Figure_03/00_CellChat_Analysis/01_Code`. The IGH D–J analysis is in `Main_Figure_05/i_M05i/01_Code`. Supplementary Figure 16 reads the supplied PHA bulk TPM table; its `00_calculate_bulk_tpm_from_counts.R` script regenerates that table from featureCounts output and the supplied gene annotations.

Figure text uses Arial. Shared colors are documented in `GLOBAL_PALETTE.md` and `palette_registry.tsv`.

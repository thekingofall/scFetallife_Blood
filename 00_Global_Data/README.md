# Shared data

`Fetal_Immune_Atlas.h5ad`, `Fetal_Immune_Atlas_TCR.h5ad` and `Fetal_Immune_Atlas_BCR.h5ad` contain the cell atlas and the TCR/BCR subsets. The atlas contains 235,494 cells; the receptor subsets contain 53,955 and 30,173 cells. Their metadata include MainID, Main_Organ, cell-type labels, gestational age and post-conception age.

`Fetal_Immune_Atlas.h5ad` is included through Git LFS. Download the TCR/BCR h5ad files, flow proportions and Olink NPX workbook from [Figshare](https://doi.org/10.6084/m9.figshare.34003890) into this directory. The sample metadata and two TPM tables are included here. See [Data and analysis setup](../00_Settings/README.md) for the flow FCS ZIP files, workspace filenames and Git LFS downloads. `Shared_Inputs` contains the additional intermediate objects and tables used in the figure analyses. These include CellChat models, receptor annotations, gene-use summaries, expression-program matrices and flow-cytometry measurements.

Each panel reads data from this directory or its own `03_PlotData` folder. R scripts resolve these paths through `00_Settings/00_setup_R.R`; Python scripts resolve them from their own location. Extracted flow-cytometry files are under `Flow_Data`.

The fitted inputs for Figure 2e, Figure 8 and Supplementary Figures 9 and 17 are described in [Shared analysis inputs](Shared_Inputs/README.md). Panel-level READMEs state whether a script starts from primary measurements, stage averages or a saved model.

`Fetal_Immune_Atlas_Seurat.rds` is generated by scripts 1 and 2 in [Figure 3 preprocessing](../Main_Figure_03/00_Preprocess/README.md). It supplies the expression input for CellChat model fitting. The fitted early- and late-stage models are in `Shared_Inputs/Main_Figure_03/00_CellChat_Models`.

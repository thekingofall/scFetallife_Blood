# Figure 6c: Flow-cytometry age associations

`01_plot_flow_age_associations.R`

Plots Spearman correlations between age and the frequencies of 44 flow-cytometry subsets across 19 PBMC samples. The statistics come from `00_Global_Data/Shared_Inputs/Main_Figure_06/bc_M06bc/M06c_Flow_Age_Association_Statistics.tsv`. Bar color represents the P-value; an asterisk marks P < 0.05.

PDF and PNG files are saved in `../02_Figures`; exported plotting tables are saved in `../03_PlotData`.

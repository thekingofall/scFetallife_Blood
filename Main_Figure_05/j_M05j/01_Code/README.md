# Figure 5j: BCR isotypes by sample

## Scripts

### `01_plot_bcr_isotypes_by_sample.R`

Reads BCR isotype counts and proportions by sample and draws the Figure 5j stacked-bar plot. It preserves the sample/tissue ordering and exports the plotting table and PDF/PNG figures.

# Figure 5k: BCR clone sizes by sample

## Scripts

### `01_plot_bcr_clone_sizes_by_sample.R`

Reads BCR clone-size counts and proportions by sample and draws the Figure 5k stacked-bar plot. It saves the source table and PDF/PNG figures.

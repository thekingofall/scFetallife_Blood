# Figure 5f: IGH, IGK, and IGL V-J pair usage

## Scripts

### `01_plot_vj_dj_pair_frequencies_and_age_associations.R`

Reads the V-J and D-J pair-frequency and age-correlation tables. It arranges pairs by gene order, fills the plotting grids, and draws frequency heatmaps with correlation-direction markers for Figures 4f and 5f. It exports the full plotting grids and the pairs selected for annotation.

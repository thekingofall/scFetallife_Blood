# Supplementary Figure 16b: Expression of Olink-matched genes across age

**[S16_assay_gene_mapping.tsv](../../../../00_Global_Data/Shared_Inputs/Supplementary_Figures/Supplementary_Figure_16/a_S16a/03_PlotData/S16_assay_gene_mapping.tsv)**

Correspondence between 61 Olink assay names, gene symbols, and Ensembl gene identifiers.

**[S16_log2TPM_long.tsv](../../../../00_Global_Data/Shared_Inputs/Supplementary_Figures/Supplementary_Figure_16/a_S16a/03_PlotData/S16_log2TPM_long.tsv)**

Expression of the 61 Olink-matched genes in 16 stimulated-PBMC samples, stored as log2(TPM + 1) with the sample ages.

**[S16_sample_metadata.tsv](../../../../00_Global_Data/Shared_Inputs/Supplementary_Figures/Supplementary_Figure_16/a_S16a/03_PlotData/S16_sample_metadata.tsv)**

The 16 bulk RNA-seq sample identifiers and the numerical ages used by the Supplementary Figure 16 scripts.

**[S16_spearman_results.tsv](../../../../00_Global_Data/Shared_Inputs/Supplementary_Figures/Supplementary_Figure_16/a_S16a/03_PlotData/S16_spearman_results.tsv)**

Spearman correlations of gene expression with age, including raw P values, BH-adjusted q values, and rank by correlation.

**[S16b_original_submission_palette_mapping.tsv](../../../../00_Global_Data/Shared_Inputs/Supplementary_Figures/Supplementary_Figure_16/b_S16b/03_PlotData/S16b_original_submission_palette_mapping.tsv)**

Gene-to-assay color assignments for the expression scatter plots, with the matching correlation statistics.

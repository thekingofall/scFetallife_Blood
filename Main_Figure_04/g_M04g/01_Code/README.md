# Figure 4g: TCR CDR3-length distributions

## Scripts

### `01_plot_cdr3_lengths_and_age_associations.R`

Reads the CDR3-length distributions and their age-association results for TRA, TRB, IGH, and light chains. It plots length frequencies across samples and the associated correlation summaries, then saves the separate/combined panels and source tables for Figures 4g and 5g.

# Figure 3b: Differential interaction strength

`01_plot_differential_interaction_strength.R` reads [M03b_differential_interaction_matrix.csv](../../../00_Global_Data/Shared_Inputs/Main_Figure_03/b_M03b/03_PlotData/M03b_differential_interaction_matrix.csv) and draws the interaction-strength heatmap for 28 PBMC cell types. Values are early-stage minus late-stage CellChat weights. The marginal bars summarize absolute changes across senders or receivers; the cell-type order and colors match the shared CellChat analysis.

The input table is generated by `Main_Figure_03/00_CellChat_Analysis/01_Code/02_summarize_interaction_strength_and_signaling.R`. PDF and PNG files are saved in `../02_Figures`.

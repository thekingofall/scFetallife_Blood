# Figure 7d: xCell scores in stimulated PBMCs

`01_plot_xcell_age_associations.R`

Plots five selected xCell scores against the recorded sample ages. It reads `00_Global_Data/Shared_Inputs/Main_Figure_07/M07d_xCell_Scores.csv`. The displayed r and P values are calculated by Pearson correlation against the age-ordered sample rank. BH adjustment covers all 39 xCell scores. The plotted regression lines use the displayed ages.

PDF and PNG files are saved in `../02_Figures`; exported plotting tables are saved in `../03_PlotData`.

# Figure 7a: Plasma protein age associations

`01_plot_plasma_protein_age_associations.R`

Reads [M07a_Plasma_Olink_spearman_plot_data.csv](../../../00_Global_Data/Shared_Inputs/Main_Figure_07/a_M07a/03_PlotData/M07a_Plasma_Olink_spearman_plot_data.csv) and plots the age correlations of 76 plasma proteins. Proteins are ordered by Spearman correlation. The P-value color scale uses the five colors in the final manuscript plot.

PDF and PNG files are saved in `../02_Figures`; plotting tables are stored in `00_Global_Data/Shared_Inputs/Main_Figure_07/a_M07a/03_PlotData`.
